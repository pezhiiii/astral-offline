# 0.1.88-dev

Generation grammar now allows either one citation or two distinct citations per line. Previously the optional second citation could duplicate the first, causing correct short unit drafts to fail structural validation. Both orders of distinct pairs remain supported; source selection remains the model's responsibility. Existing duplicate validation remains active. No post-generation answer repair is introduced.

Validation: C++ grammar-construction regression executable compiled with -Wall -Wextra -Werror and passed for all source counts 1–4, checking every allowed and disallowed pair, symbol support, and invalid source counts. This does not execute llama grammar decoding or Android. Android build and device generation remain unverified here. Citation syntax does not establish factual support.
