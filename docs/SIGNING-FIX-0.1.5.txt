Fix:
Gradle debug signing now explicitly uses .signing/astral-debug.keystore in
the repository root. CI restores the existing secret to that exact path.
CI verifies the APK cryptographically with apksigner, then compares its public
certificate digest to the certificate exported from the restored key. It only
uploads the APK and public signing report after both checks succeed.
Missing/invalid key or mismatched signer fails the build. Keep the secret and
its private backup unchanged. Never upload .signing, private keys or secret TXT.

Manual GitHub upload:
Upload app, docs, tools and .gitignore from this ZIP to repository root.
IMPORTANT: replace .github/workflows/android.yml too. This folder is hidden
on Windows; open that exact file on GitHub, click Edit and paste the complete
replacement workflow from the ZIP if necessary.
Commit: Explicitly bind and verify persistent APK signing

Local builds:
Supply your own prototype debug keystore at the same .signing path, alias
androiddebugkey and passwords android. A different local key cannot update the
community CI APK. For reproducibility, code can be built with a personal key;
do not distribute or commit the shared private CI key.
