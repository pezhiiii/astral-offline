نسخه 0.1.46-dev
فیلتر محافظه‌کارانه موضوع برای جلوگیری از ورود متن نامرتبط؛ پاسخ حداکثر 128 توکن و درخواست 60 کلمه.
این کنترل واژگانی است و صحت ادعا یا ارجاع را تضمین نمی‌کند. ممکن است منابع مرتبط با نگارش متفاوت رد شوند.
شش تست Kotlin افزوده شد؛ در این محیط اجرا نشده‌اند. SDK اندروید در دسترس نیست؛ APK ساخته یا تست نشده است.
آزمون واقعی SQLite FTS4 مربوط به رویداد اجرا و موفق شد؛ این آزمون فیلتر جدید Kotlin را اجرا نمی‌کند.
فایل‌ها را روی سورس قبلی جایگزین و از GitHub Actions بسازید. برنامه را حذف نکنید؛ مدل و منابع را حفظ کنید.
