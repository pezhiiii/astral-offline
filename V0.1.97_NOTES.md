# 0.1.97-dev — conservative scenario quotation gate

Location scenarios now request an exact complete source sentence. A new gate requires the output, excluding numeric references, whitespace and final sentence punctuation, to equal a complete location-bearing sentence in a cited source. Paraphrases are withheld and existing source-quotation fallback is used. This is intentionally restrictive and is not general semantic verification. No answers are hardcoded and no drafts are repaired. Existing 40-word limit remains; longer quotations may be withheld.

Regression cases added for exact quote, observed false mass paraphrase, wrong citation and non-scenario part. Kotlin tests and Android build not run here. Local gate smoke checks and ZIP integrity checked; on-device validation required.
